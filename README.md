## Project Description
This project aims to identify and analyze various factors that correlate with hypertension in the U.S. adult population using data from the National Health and Nutrition Examination Survey (NHANES) for the 2021-2023 cycle. Factors to be explored include demographic characteristics, dietary patterns, lifestyle behaviors, and other health conditions.

## Research Question
Which demographic, dietary, lifestyle, and co-existing health factors are most strongly correlated with hypertension prevalence and blood pressure levels in U.S. adults?

## Data Sources
* National Health and Nutrition Examination Survey (NHANES) 2021-2023
    * Demographics Data
    * Dietary Data (Individual Foods & Total Nutrients)
    * Examination Data (Blood Pressure, Body Measures)
    * Laboratory Data (e.g., Cholesterol, Glucose)
    * Questionnaire Data (e.g., Smoking, Alcohol Use, Physical Activity, Sleep, Existing Health Conditions)
* Data will be downloaded directly from the NHANES website. Links to specific datasets will be documented here.

## Methodology
1.  Data acquisition and preprocessing (cleaning, merging).
2.  Exploratory Data Analysis (EDA) to understand distributions and identify patterns.
3.  Statistical analysis to identify correlations between potential risk factors and hypertension status/blood pressure levels.
4.  Development of visualizations to present findings.

## Repository Structure
* `data/`: Contains metadata or small, processed data files. Raw NHANES data should be downloaded directly from the source.
* `analysis/`: Jupyter notebooks for data exploration and analysis.
* `docs/`: Project documentation and reports.
* `visualization/`: Saved charts and plots.
